Este es un sistema de gestión de operaciones para una empresa cervecera.
Incluye:
-Gestión de inventario
-Gestión de pedido
-Gestión de clientes
-Gestión de proveedores

El sistema fue desarrollado en Scala utilizando una arquitectura basada en capas. La UI fue desarrollada con React, Material UI y Bootstrap 5.
Se utilizó un gestor de base de datos no relacional: MongoDB.
